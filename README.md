## HERO.IO Technologies

Our website is built with modern and performance-optimized technology. The
frontend uses a combination of React.js and Tailwind CSS. Fast loading and
development experience is ensured using Vite bundler. DaisyUI and custom
Tailwind components are used in UI design. React Hooks and Context API are used
in data management. The entire system has been designed with user convenience
and a smooth experience in mind.
